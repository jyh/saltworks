## 2 · THE PROCEDURE
> Per row. **Every step produces a written mark. A row with a missing mark is not coded.**

```
S0  READ WHOLE          read the body header-to-next-header. Mark: bytes read.
                        (§6-R3 §5(b): a 1,900-char cap hid 34.7% of bytes across 70%
                         of a draw, and §1.5 runs findings over the WHOLE post)

S1  ENUMERATE FINDINGS  list every finding the row exhibits, not just the headline.
                        Mark: F1, F2, … one line each. (§1.5 all-findings unit)

S2  RUN THE LADDER      for EACH finding, in this fixed order, run all four:
                          T1 statement-level-type-traps      §3.4
                          T2 misattributed-mechanisms        §3.2
                          T3 stale-citations                 §3.3
                          T4 wrong-scope-on-a-measured-claim §3.1
                        Mark EACH: FIRE + the QUOTED SPAN, or NO + which clause fails.
                        ⛔ FOUR MARKS PER FINDING. NOT ONE.

S3  FILE                the FIRST test marked FIRE wins. Mark: the class + that span.

S4  RESIDUAL            no test marked FIRE ⇒ OTHER. Mark: "0 of 4 fired".
```

### 2.1 ⭐ WHY FOUR MARKS AND NOT ONE — THE ONE DESIGN DECISION THAT MATTERS
**A ladder violation requires writing a contradiction.** *To file `69485` at T4 under this
form I must write `T2 FIRE <span>` and then `filed T4` on the next line.* **AMBIG becomes
unwritable when a test is marked FIRE.** ⇒ ***THE FORM DOES NOT ASK ME TO BE MORE CAREFUL. IT
MAKES MY MEASURED FAILURES REQUIRE A VISIBLE SELF-CONTRADICTION*** — my own banked law that a
form which automates the claim beats one that reminds you to make it.

📌 **And it prices honestly: four marks per finding is ~4× the writing of a single class
call.** *That cost is the deliverable, not a side effect. A procedure that were cheaper would
be the one both passes already ran.*

### 6.1 ⛔ AND THE CLAIM IN §2.1 IS TOO STRONG — I AM NARROWING IT MYSELF
§2.1 says the form makes these failures *"require a visible self-contradiction."* **That holds

**What the form actually does, stated precisely:**
